IMPORTANT: search code with these tools, never with grep, rg, find or by reading files to look around. One call searches {repositories} at once and skips gitignored files. nametrail_lookup takes a name, part of a name, a file name, or a few words, and answers where it is, with its code when it has one definition; nametrail_uses shows who uses a name, or which files depend on a file; nametrail_impl what extends or implements a type; nametrail_grep finds exact text in every repository at once. Fall back to other tools only when an answer did not have what you need.
